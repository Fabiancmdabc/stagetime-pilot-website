# StageTime-Pilot Website

Kostenlose Produktseite für StageTime-Pilot (Tasty-World).

```bash
npm install
npm run dev    # http://localhost:3002
npm run build
```

Deploy: Vercel (Root = dieses Verzeichnis). Nach Desktop-Builds Installer in `public/downloads/` legen und `src/lib/releases.ts` aktualisieren.
